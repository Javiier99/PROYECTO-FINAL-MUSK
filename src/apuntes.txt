--------------------------------------------------------------------------------
1. PRINCIPIOS DE PROGRAMACIÓN FUNCIONAL
--------------------------------------------------------------------------------
• Reglas Clave:
  - Usar funciones puras (mismos argumentos = siempre mismo resultado, sin efectos secundarios).
  - Inmutabilidad: NUNCA modificar las estructuras originales, devolver siempre nuevas listas o dicts.
  - Utilizar funciones de orden superior: filter(), map(), reduce(), lambdas.

• Ejemplo de Función Pura (Filtrado por Categoría):
  
  def filter_sales_by_category(sales, category):
      return list(filter(lambda s: s.category == category, sales))

• Ejemplo de Función Pura (Filtrado por Rango de Fechas):

  def filter_sales_by_date_range(sales, start_date, end_date):
      return list(filter(lambda s: start_date <= s.date <= end_date, sales))

• Operaciones Funcionales Comunes:
  - Transformar datos:  map(lambda s: s.amount, sales)
  - Filtrar registros:  filter(lambda s: s.amount > 100, sales)
  - Acumular valores:   reduce(lambda acc, s: acc + s.amount, sales, 0)


--------------------------------------------------------------------------------
2. INTEGRACIÓN Y MANIPULACIÓN CON PANDAS
--------------------------------------------------------------------------------
Pandas se utilizará de forma específica para las tareas de cruce, agregación
y exportación masiva de datos:

• Cruce de Datos (Merge):
  Unir el conjunto de Clientes (JSON) con Ventas (CSV) utilizando 'client_id':
  
  df_merged = pd.merge(df_sales, df_clients, on="client_id", how="inner")

• Agregaciones y Grupos (Groupby):
  - Por Categoría:  df.groupby("category")["amount"].agg(["sum", "mean", "count"])
  - Por País:       df.groupby("country")["amount"].sum()
  - Por Mes:        df.groupby(df["date"].dt.to_period("M"))["amount"].sum()

• Resumen de Totales:
  Generación de métricas globales (Total Ventas, Promedio, Gasto Máx/Mín).

• Exportación a JSON:
  Preparar las estructuras agregadas en formato dict/JSON para su exportación:
  
  result_json = df_grouped.to_json(orient="records", indent=4)
